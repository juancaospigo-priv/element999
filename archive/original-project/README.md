# Element999

Element999 identifica el proceso, dato o decisión que falta en una empresa y lo convierte en una mejora operativa medible.

La Fase 1 está validada por el fundador con una tarifa de cálculo de 80 EUR/h. La Fase 2 está entregada para revisión visual, con identidad digital y prototipo navegable. Las conexiones de producción corresponden a las fases siguientes.

- [Especificación de producto y operación](docs/FASE_1.md): posicionamiento, catálogo, cotización, experiencia, arquitectura y aceptación.
- [Backlog de producción](docs/BACKLOG.md): trabajo por fase, dependencias, esfuerzo y presupuesto de planificación.
- [Entrega de Fase 2](docs/FASE_2.md): pantallas, validación y capturas.
- [Sistema de diseño](DESIGN.md): identidad, tokens y comportamiento de componentes.
- [Prototipo local](prototype/README.md): instrucciones de apertura y comprobación.
- [Prompt para Lovable](docs/PROMPT_LOVABLE_FASE_2.md): continuidad a partir del producto y diseño definidos.

La tarifa validada y el alcance definido constituyen la base interna para continuar. Los plazos, costes internos y presupuesto operativo son supuestos de planificación; no se han publicado condiciones comerciales ni autorizado gastos.
